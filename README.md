# Donkey Diff

**Open source Git client for Mac.** Free to use, under the MIT license.

Review changes, manage branches and worktrees, and commit your work.

**[Download for Mac](https://github.com/DonkeyCut/donkey-diff/releases/latest)** · [Website](https://donkeycut.github.io/donkey-diff/) · [MIT license](LICENSE)

![Donkey Diff showing changed files, code diffs, and project chat](docs/poster.jpg)

## Features

- **Review changes.** Read unified or side-by-side diffs with syntax highlighting and full-file context. Filter changed files or browse the repository.
- **Preview assets.** See images, SVGs, audio, and video inline alongside your changes.
- **Stage and commit.** Double-click a file or folder to stage it. Review staged changes, write a message, and commit.
- **Manage branches and worktrees.** Switch between projects in tabs, create branches, and keep separate worktrees open.
- **Explore history.** Browse commits, inspect their changes, or select two commits to compare.
- **Use Codex or Claude.** Ask an agent to explain code, make an edit, or review changes.
- **Handle everyday Git tasks.** Fetch, pull, push, stash changes, and resolve conflicts.
